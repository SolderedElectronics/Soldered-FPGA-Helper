FPGA Helper by Soldered

▶ Info & Instructions

FPGA Helper by Soldered is a Visual Studio Code extension that helps you get started with FPGA projects using a friendly graphical interface, with first-class support for Soldered boards.

Note: This extension is experimental and is actively being developed.

  • Project: New to this? Use the Project section to generate a working example (blinky) automatically.
  • Board: Select your target board. Currently only TinyFPGA MINI1 is supported.
  • Board Port: Select the serial port your board is connected on. The board only shows up while its bootloader is active.
  • Build & Upload: Synthesize your design and program it onto the board. Opens the integrated terminal to run the toolchain — first run downloads the toolchain, so it takes longer.

You can explore the source code, submit issues or pull requests, and leave feedback on the extension's GitHub page.
